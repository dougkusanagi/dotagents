# 0.2.0

- Adicionado: os agentes sempre respondem em português do Brasil (pt-BR).
- Adicionado: instalação e sincronização no Windows, com cópia dos arquivos quando links simbólicos não são permitidos.
- Adicionado: backup privado das memórias com envio durante a sincronização e restauração durante a instalação. As regras também permitem memorizar fatos e referências a pedido.
- Adicionado: guia de controle de pulo para jogos de plataforma e instruções para criar diagramas com Archify.
- Alterado: as regras pedem um README inicial atualizado e o registro de decisões difíceis de reverter em ADRs, considerando o efeito conjunto das mudanças.
- Alterado: as convenções do projeto prevalecem sobre os padrões globais. “Main” e “master” se referem ao branch principal existente.
- Alterado: as regras orientam testes locais, hooks de pré-push em projetos com suíte local, correção de testes intermitentes e commits com uma única finalidade. PRs visuais pedem capturas antes e depois, anexadas pelo GitHub CLI.
- Alterado: a versão passa a ser definida por entrega nos projetos com consumidores de versão. Tags e binários de distribuição ficam restritos a apps nativos.
- Alterado: as regras de interface refinam a verificação responsiva, o seletor de tema e a validação de formulários, incluindo campos monetários e identificadores brasileiros. Novos projetos Laravel usam pt-BR e o fuso de São Paulo por padrão.
